# Negin Middle East

A modern and responsive corporate construction company website built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

---

## ✨ Features

- Responsive Design
- Modern UI
- Hero Image Slider
- Dynamic Project Pages
- About Us Page
- Custom 404 Page
- Mobile Navigation
- Desktop Dropdown Menu
- Reusable Components
- Optimized Images with Next.js

---

## 🛠 Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS

---

## 📂 Project Structure

```
app/
components/
public/
```

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/negin-middle-east.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
